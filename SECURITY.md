# Security

Report a vulnerability in an extension of this repository privately, through GitHub's
private vulnerability reporting on this repository (Security tab, "Report a vulnerability").
Do not open a public issue or pull request for it.

Include the extension and version (tag) concerned, the chain and address if it is deployed, and
steps or a Foundry test that reproduces the issue.

Vulnerabilities in the Frontier hook itself belong to
[FrontierFun/factory-hook](https://github.com/FrontierFun/factory-hook).
